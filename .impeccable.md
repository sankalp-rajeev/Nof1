# Design Context

Creator-confirmed direction, 2026-10-31. Audience: people with chronic conditions
tracking daily observations and conducting structured personal experiments.
Jobs: chat/check-in, inspect timeline and evidence, run a 14-day experiment, review
an honest verdict; a phone may be the first viewing context.

Quiet research journal: warm paper, dark green, restrained typography. No emojis,
mascots, celebratory verdicts or features beyond PRD 12. Mobile-first stacked panes.
Persistent research/not-medical-advice banner visible on every screen.

Red flags override the calm palette: unmistakable high contrast, distinct border,
plain text. BASELINE, ON and OFF need large text plus distinct shapes or patterns,
never color alone. Verdict limitation and sample size use the same size as the
verdict label. WCAG AA contrast. API and demo clock are implemented before UI.
